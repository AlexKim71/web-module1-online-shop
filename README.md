**Платформа:** .NET 10.0

## Технічний стек

- **Мова:** C# (.NET 10)
- **Веб-фреймворки:** ASP.NET Core Razor Pages, Blazor (Interactive Server)
- **База даних:** SQLite (провайдер `Microsoft.Data.Sqlite` версії 10.x)
- **Доступ до даних:** ADO.NET (параметризовані запити, транзакції)

## Структура рішення (Solution)

- `Domain` — сутності предметної області (`Category`, `Resource`, `Request`), інтерфейси та бізнес-правила валідації.
- `Infrastructure` — реалізація ADO.NET-репозиторіїв для SQLite.
- `RazorWeb` — серверний вебінтерфейс (каталог товарів, CRUD, створення та скасування заявок).
- `BlazorWeb` — інтерактивний каталог та калькулятор вартості (без зміни БД).
- `ConsoleApp1` — консольний інструмент для валідації XML за DTD/XSD та демонстрації трьох парсерів.

## Інструкція із збирання та запуску

> **Увага:** Для уникнення конфліктів із середовищем Visual Studio запуск рекомендується виконувати через термінал (Command Prompt, PowerShell або вбудований термінал VS Code) з кореневої папки рішення, де знаходиться цей файл.

1. Переконайтеся, що у вас встановлено **.NET 10 SDK**.
2. Відновіть пакети та зберіть рішення:

   ```bash
   dotnet restore
   dotnet build
   ```

### Запуск Razor Pages (головний інтерфейс магазину)

```bash
dotnet run --project RazorWeb
```

Після запуску перейдіть за посиланням `http://localhost:...`, яке з'явиться в консолі.

### Запуск Blazor (інтерактивний калькулятор)

```bash
dotnet run --project BlazorWeb
```

### Запуск консольного валідатора XML

```bash
dotnet run --project ConsoleApp1
```

## База даних

База даних SQLite (`shop.db`) автоматично створюється під час першого запуску `RazorWeb` у папці `Data/`.

Для створення використовуються скрипти:

- `Data/init.sql` — створення схеми таблиць з обмеженнями (`CHECK`, `FOREIGN KEY`).
- `Data/seed.sql` — заповнення початковими даними (3 категорії, 12 товарів).

Обидва вебпроєкти (`RazorWeb` та `BlazorWeb`) використовують один і той самий файл бази даних.

## XML

Файли для обміну каталогом знаходяться в папці `Xml/`:

- `catalog.xml` — демонстраційні дані.
- `catalog.dtd` — схема синтаксичної валідації.
- `catalog.xsd` — схема валідації типів даних та унікальності SKU.
